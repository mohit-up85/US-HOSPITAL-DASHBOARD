# US-HOSPITAL-DASHBOARD
Data Analytics Dashboard

An interactive Data Analytics Dashboard designed to transform raw data into meaningful insights through clear and dynamic visualizations.
This project demonstrates the process of data cleaning, analysis, and visualization to support better data-driven decision making.

The dashboard helps users analyze trends, monitor key performance indicators (KPIs), and explore data efficiently using interactive charts and filters.

🎯 Project Objective

The main goal of this project is to demonstrate practical data analytics skills by converting raw datasets into interactive and easy-to-understand dashboards that highlight important patterns and insights.

🚀 Features

Interactive dashboard with dynamic visuals

Key Performance Indicator (KPI) tracking

Data filtering and slicing options

Clear charts and graphs for better insights

Easy-to-understand layout and design

Insightful trend and performance analysis

🛠 Tech Stack

Tools & Technologies Used

Power BI – Dashboard creation and visualization

Microsoft Excel – Data preparation and cleaning

Data Analysis Techniques – Identifying trends and patterns

Data Visualization – Presenting insights using charts and graphs
